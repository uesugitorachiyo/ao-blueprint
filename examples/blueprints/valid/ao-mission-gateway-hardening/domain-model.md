# Domain Model

- Mission gateway readback: Telegram/A2A intent or compatibility evidence.
- Freshness classification: `fresh`, `stale`, or `unknown`.
- A2A fixture server readback: local Agent Card and JSON-RPC path evidence.
- Timeline compaction readback: digest-bound retained route and step timeline.
- Provenance node: Atlas metadata entry naming a Mission evidence source.
- No-promotion readback: Promoter evidence that a gateway packet does not prove
  a class transition.
